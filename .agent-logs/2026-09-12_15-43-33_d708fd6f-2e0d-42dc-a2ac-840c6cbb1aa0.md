## The change

```ts
async function readOrSeed<T>(fromDatabase: () => Promise<T>, fromSeed: () => T): Promise<T> {
  if (!hasMongo) return fromSeed();
  try { return await fromDatabase(); }
  catch (err) { /* warn, throttled to once per 30s */ return fromSeed(); }
}
```

`listMeetings`, `getMeeting`, `getTranscript`, `getSummaries`, `getAnalytics`, `getHighlights`. The seed branches are the **same expressions as before**, just moved into a thunk — no fallback logic was rewritten. Net +98/−49.
