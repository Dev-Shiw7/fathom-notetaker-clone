### 1. Auto-filling "Notetaker" & Enabling the Join Button ([prejoin.ts](file:///Users/srichand/8x-Assessment/backend/src/meet/prejoin.ts))
- **Cause**: Playwright's `locator.fill('Notetaker')` set the DOM value property directly without typing events. Google Meet's Angular/Closure framework didn't register the input, leaving the "Ask to join" button disabled unless typed into manually.
- **Fix**: Updated `setDisplayName` to click into the field, clear it, simulate human typing with `pressSequentially('Notetaker', { delay: 30 })`, and dispatch `input`/`change` events. Google Meet now activates and enables the join button immediately.

- **Cause**: When the bot finished the call and posted the stub transcript to `/api/bot/transcript`, `saveBotTranscript` only attempted to write to MongoDB. If the DB connection was slow or cold, it failed silently without persisting to the local store, and in-memory fallback stores weren't preserved across Next.js requests.
- **Fix**:
  - Mounted in-memory stores on `globalThis` so saved transcripts and meetings persist across API calls and page reloads.
  - `saveBotTranscript` now writes to the in-memory store before attempting MongoDB, ensuring the meeting is immediately visible in the Library and Call View.
  - `listMeetings()`, `getMeeting()`, `getTranscript()`, and `getSummaries()` now query the store so bot recordings show up on the homepage instantly.
  - Dynamic API URL (`apiUrl = options.appUrl || 'http://localhost:3000'`) is used when posting transcripts.
